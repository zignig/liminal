# Authentication and Authorization

This is a irpc server back by a turso sql database , that handles
both sides of auth on the iroh and wash sides. 

The [rcan](https://docs.rs/rcan) will provide fine grained access control to all the things.

## Provides 

[ ] iroh access based on endpoint ids
[ ] rcan collections to auth components access and neighbors
[ ] username/password
[ ] storage for secret keys (signing,tls for services , frost keys)
