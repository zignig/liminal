# Admin web interface

This will become a [wasm-cloud](https://wasmcloud.com/) admin interface.

It uses

1. axum for serving
2. [oat](https://oat.ink/) for css
3. [mithril](https://mithril.js.org/) for SPA applications
4. Custom hostplugin to commands to and from the host.

All wrapped up into a nice web interface.
